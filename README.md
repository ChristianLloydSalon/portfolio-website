## About the site itself

I designed and built the site myself. It's styled like a video game: a short intro plays when you arrive, the background scenery is drawn in code, and there's a light "Sunrise" theme and a dark "Dusk" theme. It works on phones, and if your device is set to reduce motion, the animations are switched off.

Built with React, TypeScript, Tailwind CSS and GSAP, and hosted on Firebase.
